Privacy Policy

Anvil is designed to keep developer data useful without turning the workspace into a surveillance service.

Last updated: October 8, 2026

What Anvil processes

When you use public GitHub mode, Anvil requests public GitHub profile, repository and event data needed to render the workspace. Contribution history may be retrieved from the public contributions API configured by the app.

When you connect the GitHub App, Anvil receives authorization information from GitHub and uses the resulting server-side session to request GitHub data on your behalf. The OAuth access token is not intentionally exposed to browser JavaScript.

What stays in your browser

Theme and profile preferences are stored in browser local storage. An optional personal access token is stored in session storage when you explicitly choose to remember it for the current browser session. Older persistent token storage is cleared by the app.

Cookies

Anvil uses strictly necessary, secure, same-site cookies for GitHub App authentication and OAuth state. Anvil does not use advertising cookies or analytics cookies.

Third parties

GitHub and the contributions API are external services used to provide requested functionality. The interface also loads its icon library and font resources from external CDNs. Their own policies govern those services.

Data control

You can disconnect the GitHub App session from Anvil. You can clear the optional browser token and local preferences from the app. Public GitHub data shown in Anvil is fetched on demand rather than presented as a separate Anvil-owned profile database.

Contact

For security issues, use the process described in the Security page.
