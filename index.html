Developer workspace

Let every commit tell its tale.

Anvil gathers GitHub activity, repository fortunes, releases, and local Git history, that the work behind the work may stand revealed.

ActivityTrace the rise and fall of contributions, public events, and commits through the passing days.
RepositoriesSurvey each project’s tongue, stars, forks, and latest stirrings; mark what thrives and what lies quiet.
Git intelligenceBring forth a git log, and reckon commits, working days, and unbroken streaks without a server.
ReleasesCall recent releases into view, and see what each repository hath sent into the world.
ReportsSet thy findings down as JSON, CSV, or Markdown, or send a report to the printer.

Data and privacyDesigned to keep credentials out of the UI
GitHub App

When connected, OAuth credentials are held server-side in an encrypted session cookie. The access token is not exposed to browser JavaScript.

Local Git

Paste a Git log and analyse it in the browser. The local analysis path does not require GitHub authentication.

Personal access token

Optional browser-side authentication for GitHub API requests. Anvil keeps it in browser storage according to the selected preference and sends it only to GitHub.

No advertising analytics

Anvil does not use advertising or analytics cookies. Necessary authentication cookies and browser preferences are documented in the privacy and cookie policies.

Common questions

What is Anvil?

Anvil is a developer workspace that turns GitHub activity, repositories, releases and Git history into a focused view of development activity.

What happens when I connect GitHub?

Anvil uses a server-side GitHub App session. The OAuth access token stays on the server and is not exposed to browser JavaScript. The connected account is then loaded into the workspace.

Can I use Anvil without GitHub?

Yes. Local Git mode can analyse pasted git log output without GitHub authentication.
