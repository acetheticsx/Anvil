About Anvil demo project

Anvil is a single-file developer activity dashboard, coded by @aceyash-dev as a demo.

It has no backend, no build step and no tracking. Every request goes straight from your browser to the public GitHub API and the open github-contributions-api. Nothing is stored server-side. Preferences and an optional access token live in your own browser storage, and you can clear them at any time.

GitHub mode Profile, contributions, repositories, public events and releases.
Local Git mode Paste git log output and analyse it completely offline.
Access token Optional. Raises the API rate limit and unlocks private-repository metadata you can already see.
Exports JSON, CSV, share URLs and a print-friendly report.
Try the demo Load the public profile of @aceyash-dev, the author of this page.

Built with vanilla JavaScript, the GitHub REST API and the open contributions API. No frameworks, no analytics, no cookies.
