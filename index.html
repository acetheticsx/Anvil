About Anvil demo project

Anvil is a single-file developer activity dashboard, coded by @aceyash-dev as a demo.

Anvil is a lightweight client with optional server-side GitHub App authentication. Public GitHub data and the github-contributions-api are fetched as needed. GitHub App sessions use secure server-side cookies; an optional personal access token is kept only for the current browser session and is never persisted to local storage.

GitHub mode Profile, contributions, repositories, public events and releases.
Local Git mode Paste git log output and analyse it completely offline.
Access token Optional. Raises the GitHub API rate limit for browser-side requests. GitHub App access is handled separately.
Exports JSON, CSV, share URLs and a print-friendly report.

Anvil in plain language

What is Anvil?

Anvil is a developer workspace that turns GitHub activity, repositories, releases and Git history into a focused view of project health and development activity.

What happens when I connect GitHub?

Anvil uses a server-side GitHub App session. The OAuth access token stays on the server and is not exposed to browser JavaScript. When connected, Anvil automatically loads the authorized GitHub account into the workspace.

Does Anvil use analytics or advertising cookies?

No. Anvil does not use advertising or analytics cookies. Authentication uses strictly necessary session cookies, while local preferences and an optional personal access token use browser storage as described in the privacy and cookie policies.

Built with vanilla JavaScript, the GitHub REST API and the open contributions API. Anvil is designed to keep the interface fast, understandable and privacy-conscious.
