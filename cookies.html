Cookie Policy

Anvil uses only the storage needed for authentication and user-selected preferences.

Last updated: October 8, 2026

Strictly necessary cookies

GitHub App authentication uses secure, HttpOnly, same-site cookies so the browser can maintain a server-side session. OAuth state is also protected with a short-lived signed cookie during the authorization flow.

No tracking cookies

Anvil does not set advertising, analytics, social tracking, or cross-site profiling cookies.

Browser storage

Browser local storage keeps non-secret preferences such as theme and the last profile. An optional personal access token uses session storage when you explicitly enable the remember option. Session storage is not a cookie and is scoped to the browser tab/session.

Cookie notice

Anvil shows a cookie information banner so you can see what storage is used. Dismissing that notice stores only a local browser preference so the notice is not repeatedly shown. This preference is not a tracking cookie.

Managing storage

You can clear the optional token from the Access token controls in Anvil. Browser settings can also clear local storage and session storage. Clearing authentication cookies will sign you out of the GitHub App connection.
